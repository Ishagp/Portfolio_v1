# Isha Gupta - Personal Portfolio Website

A modern, responsive, and recruiter-friendly portfolio website for **Isha Gupta** (B.Tech CSE - AI/ML • Data Analyst). Built with **HTML5, Tailwind CSS, Lucide Icons, Chart.js, and vanilla ES6 JavaScript**.

---

## 🌟 Highlights & Features

1. **Hero / Home**:
   - Title: `And I am a Data Analyst`
   - Quick stats: B.Tech CGPA (8.58 / 10), Class 12th (92.80%), Class 10th (93.33%), Volunteering at Akshargyan
   - Direct contact & social actions (GitHub, LinkedIn, Email, Phone, Download CV)

2. **About Me**:
   - Crisp narrative focusing on data-driven engineering, machine learning pipelines, and analytical dashboards
   - Core focus areas and technical domains

3. **Skills & Tooling**:
   - Categorized grids: Programming Languages, Data Analysis & BI, Machine Learning & AI, Web Technologies, Developer Tools
   - **Live skill search bar** to filter skills dynamically in real-time

4. **Featured Projects ⭐**:
   - Machine learning prototypes, Power BI business intelligence dashboards, and responsive web applications
   - **Interactive category filter tabs**: All | Machine Learning | Data & BI | Web & Analytics
   - Direct GitHub repo links, live demo links, and detailed case study popup modals

5. **Interactive Live Dashboard**:
   - Embedded interactive analytics dashboard widget with real-time KPI metrics and dynamic chart toggles

6. **Education & Certifications**:
   - Academic history at JSS Academy of Technical Education (8.58 CGPA) and senior secondary credentials
   - Verified certification credentials with direct verification links

7. **Official Resume**:
   - Embedded clean resume preview modal
   - Dedicated ATS-formatted printable web resume (`assets/resume.html`) ready to print or export to PDF

8. **Contact & Micro-interactions**:
   - Direct contact cards (Email, Phone, LinkedIn, GitHub, Location)
   - Validated message form with client launcher
   - Floating smooth-scroll Back-to-Top button
   - Fully responsive design across mobile, tablet, and desktop screens
